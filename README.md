# 📌 PEP
## Programa de Execução de Exercícios
Sistema web desenvolvido  para a cadeira de Projeto e desenvolvimento  da Faculdade Senac Porto Alegre.

# 🏋️‍♂️ Sobre o Projeto
O PEP é um sistema web criado para auxiliar personal trainers na programação e gerenciamento de exercícios físicos destinados aos seus alunos.
A plataforma permite organizar treinos de forma estruturada, facilitando o acompanhamento e a execução dos exercícios.

# 💻 Tecnologias Utilizadas
O sistema foi desenvolvido utilizando as seguintes tecnologias:
- PHP
- Laravel
- HTML
- CSS
- Bootstrap
- MySQL

Essas ferramentas foram escolhidas para garantir organização do código, produtividade no desenvolvimento e uma interface responsiva.

 # 🚧 Status do Projeto
 ### FASE ALPHA
O projeto encontra-se em fase inicial de desenvolvimento, podendo sofrer alterações estruturais, funcionais e visuais.
